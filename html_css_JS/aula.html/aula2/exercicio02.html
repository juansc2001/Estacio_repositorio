materias

  • Montagem e Manutenção de Computadores: Estudo de peças, placas-mãe, fontes, testes de componentes e reparo de defeitos em hardware.
  • Lógica e Linguagens de Programação: Introdução a algoritmos, estruturas de dados e linguagens como Python, JavaScript ou C.
  • Redes de Computadores: Configuração de redes locais (LAN), roteadores, cabos, protocolos de comunicação e noções de segurança e firewalls.
  • Sistemas Operacionais: Instalação, configuração e gerenciamento de sistemas como Windows e Linux.Banco de Dados: Criação e modelagem de tabelas, consultas SQL e rotinas de backup.
  • Desenvolvimento Web: Noções de HTML, CSS e criação de sites ou pequenos sistemas para a internet.
